# Changelog

## [1.0.0] - 2026-11-02

### Added
- Реализации для 13 языков: C, C++, Python, JavaScript, TypeScript, Java, C#, F#, Go, Rust, Bash, Prolog и Assembler (AArch64).
- README с описанием окружения, таблицей версий инструментов и команд сборки/запуска, примером вывода, описанием кириллицы в C/C++ и assembler-варианта.
- Feature-ветка `feature/fsharp` и разрешённый merge-конфликт.
- Файл `.gitignore` для исключения артефактов сборки.
- Файл `.gitattributes` для принудительного использования LF (Unix) переносов строк.

### Fixed
- В приветствии выводится константа 304, а вычисленный `control_value` (6384) — в поле `Control`.
- В Prolog правило `control_value` теперь вычисляет `304 × student_number`.
